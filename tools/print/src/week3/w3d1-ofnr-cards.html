The OFNR card game build it together

Group
1

Groups of 4–5 in a circle. Deal 4–5 cards each. Keep them secret.

2

One student reads an O card aloud and puts it on the table.

3

Others offer the best F, then N, then R card. Discuss: which fits best?

4

Set complete? Read it aloud calmly. Next student starts a new set.
